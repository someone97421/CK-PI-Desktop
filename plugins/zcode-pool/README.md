# ZCode Pool

这是一个助手（PI-Desktop）独立插件，复用本机 ZCode 登录，通过官方客户端的 Start Plan 通道提供模型。面板参考 WTQ Pool 的布局与操作方式，不修改 WTQ Pool。

## 使用

1. 安装 Node.js 22 或更新版本，并在 ZCode 桌面端登录。
   0.2.0 需要包含 ZCode 会话工作目录传递改动的本 fork 主程序；旧主程序仅安装新插件无法自动跟随目录。
2. 安装 `.piplug`，打开 ZCode Pool 面板。第一次默认停止，不会自动发送模型请求。
3. 点击刷新检查客户端和登录文件。自动定位失败时，在路径设置中填写客户端自带的 `resources/glm/zcode.cjs`。
4. 点击启动，等待“已连接”。连接测试会真实发送一条短消息并消耗账号额度。
5. 在模型选择器中选择「ZCode Pool · Start Plan」。目录或模型开关改变后，按面板提示重载插件。

端点固定为 `http://127.0.0.1:41971/v1`。端口被占用时明确报错，不静默切换到另一个地址。

## 当前范围

- 使用本机当前登录，账号摘要不展示 token 或完整个人信息。
- 使用 `desktop-local` 方式启动官方 `zcode.cjs`，按当前内置配置注册 `account:zai-start-plan`，从客户端会话取得模型元数据。
- 仅连接 Start Plan，不回退到 API Key、个人自定义供应商或其他套餐。
- 提供 OpenAI Chat Completions 入口，支持文本、流式正文与思考、非流式回答、用量统计。
- 每次请求建立独立 ZCode 会话，携带本次完整文本历史及所属 PI 会话的工作目录。普通项目使用项目目录，隔离会话使用 worktree，临时会话使用自选目录或会话 scratch；切换前台会话不会改变已有请求的目录。
- 断开 HTTP 连接会取消请求；停止或卸载插件会终止它创建的客户端进程树。
- 日志仅保留本次运行最近 100 条摘要，不记录对话正文或凭据。

客户端目录中的模型不等于账号对每个模型都有额度。实际权限与额度以服务端响应为准；插件不展示猜测的余额。

## Agent 桥接边界

这是 ZCode Agent 桥接，不是透明模型传输。PI 的系统消息和历史被转成带角色标签的文本交给 ZCode；PI 原生工具、子代理、MCP 和工具审批不透传。工具调用由 ZCode 自己执行，不会在 PI 中形成原生工具卡片。

「允许 ZCode 自动批准工具执行」默认关闭，沿用验证时的 `build` 模式；关闭表示拒绝 ZCode 发来的授权请求，不是操作系统沙箱，也不等于禁用所有无需授权的工具。打开后，ZCode 可在请求所属会话的目录中自动执行其工具。路径和该开关需要先停止服务再修改。面板连接测试使用插件数据目录中的 `workspace/`。

当前不支持图片、音频和附件内容块，不转发 OpenAI 的强制工具调用。`max_tokens`、temperature 等模型采样参数由 ZCode 运行时控制；插件不宣称可以覆盖。思考级别使用客户端实际声明的档位，不支持的值回退到该模型默认档位。

工作目录由宿主按请求通过本机 `x-pi-zcode-workspace` 头传递，值为 UTF-8 JSON 的 base64url，包含 `version: 1`、`sessionId`、`path`。插件校验目录存在，并按会话与目录生成工作区标识，不修改进程全局 cwd。主会话、选用此模型的 PI 子代理及各自的压缩请求均带目录，子代理优先使用当前委派 worktree；缺少目录信息时明确报错。远程工作目录、原生 Pi 会话和没有会话目录的插件单次补全暂不支持；不从对话正文推断路径。

官方 Agent 自带上下文：前期最小链路探测的短请求约有 2 万输入 token。多轮文本历史完整重放也会增加开销，不能按普通短 HTTP 请求估算成本。

## 文件与数据

- 源码：`main.js`、`lib/`、`renderer/`，无需安装 npm 依赖或编译。
- 登录文件：所选数据基目录下 `.zcode/v2/credentials.json`，只读，内存解密。
- ZCode 配置：从当前运行配置查找；不改写 ZCode 登录文件、模型配置或已有会话。
- 插件数据：宿主分配的数据目录，保存模型目录缓存与连接测试目录。
- 模型声明：沿 WTQ 方式更新本插件 `manifest.json`；宿主重载插件后采用新声明。

自动定位覆盖 Windows 运行中的客户端、默认安装位、常见盘根安装位，以及 macOS 常见安装位。其他布局可手动填写 CLI 路径。桌面客户端升级后若内置配置与内核不兼容，应让两者版本一致。
