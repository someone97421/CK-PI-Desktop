# Computer Use（Win 版）

适用于 Windows x64 的独立桌面控制插件，版本 0.3.4。插件包内置 cua-driver 0.28.2，首次启动自动离线解压到插件数据目录，无需另行安装驱动、Python、Node 或配置 PATH。驱动所需的用户目录环境由插件自动补齐；宿主未提供用户目录时，配置持久保存在插件数据目录的 `driver-home` 中。

在应用的插件页面导入 `cn.star.computer-use-0.3.4-win-x64.piplug` 并启用。默认自动启动；启动成功后可让智能体操作桌面应用。插件 ID 为 `cn.star.computer-use`，导入会更新已有同 ID 插件，并沿用其设置。

面板提供启动、急停和最近操作画面。允许列表在“设置”中，技术信息与 Doctor 在“诊断”中，只有主动点击才运行诊断。运行失败时点击“修复并启动”，插件会从内置包恢复缺失或损坏的运行文件并重启；若内置包本身损坏，请重新导入插件包。手动急停后需在面板重新启动。

保留原有工具权限、拒绝列表、允许列表和 Esc 急停行为。驱动只通过本地子进程运行，退出插件时停止。

开发者使用 PluginPack 对本目录打包，再将输出文件名标注 `-win-x64`。`.piplug` 外层使用宿主支持的无压缩格式，内部保留官方压缩运行包以满足宿主 50 MB 大小限制。驱动来源与校验值见 `vendor.json`，许可证见 `LICENSE` 和 `THIRD_PARTY_NOTICES.md`。
