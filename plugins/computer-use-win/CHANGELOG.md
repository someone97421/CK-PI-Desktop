# 更新日志

## 0.5.0

- 修复同一窗口连续查询不同关键词时漏掉控件的问题，操作索引仅限最近一次查询的命中项。
- 同步 cua-driver 0.53.0，适配控件令牌、截图坐标和窗口状态接口。
- 面板支持升级旧版驱动，并缓存近期探测结果；「重新检测」可强制刷新。

## 0.4.0

- 新增 Office 知识与桌面操作技能，理论支持 WPS。
- Win环境中若存在 PowerShell 7，则优先使用。
- 支持前台/后台操作切换、局部截图，完善焦点与截图状态提示。
- 优化动态控件、菜单、保存对话框及中文文件名读取。
- 改进快捷键、粘贴和窗口关闭验证，修复误打开文件、删除键抢焦点等问题。
