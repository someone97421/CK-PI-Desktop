# 下一阶段：Codex 宠物复刻缺口

第一阶段交付独立 `local.codex-pet` 插件，用既有宿主能力实现宠物库、图集播放、浮窗控制、快捷聊天和活动通知。0.1.5 补充模型正文气泡、点击唤起主程序会话和 FPS 设置，并在宿主 SDK 增加 `pi.ui.showMainWindow()`；未改动数据库、系统协议注册或智能体提示词。其余后续缺口仍按下表推进。

## 资料与确认范围

实现依据固定在本轮读取的公开源版本：

| 来源 | 固定版本 | 已确认内容 |
| --- | --- | --- |
| OpenAI `openai/skills`，`skills/.curated/hatch-pet/` | `49f948faa9258a0c61caceaf225e179651397431` | `pet.json`、PNG/WebP、标准 v1 8×9 网格、192×208 帧、1536×1872 图集，以及 `references/animation-rows.md` 的动作行与帧时长 |
| OpenAI `openai/codex`，`codex-rs/tui/src/pets/model.rs` 及宠物运行逻辑 | `8e23d1836fd22d1c920533f39851db1c7d795744` | 可选元数据默认值、自定义 frame/animations、默认 fps、动作循环与回退、非 idle 标准动作播放三遍后进入 idle |
| 公开安装链接约定 | 本轮官方资料 | `codex://pets/install` 与 `name`、`imageUrl`、`description`、`spriteVersionNumber` 参数；出现 v2 参数不等于公开了 v2 播放规格 |

idle 使用面向桌面素材的 `[280,110,110,140,140,320]` 毫秒时长。公开 TUI 模型中的 idle 时长是这些值的六倍；本插件没有把 TUI 节奏当作桌面节奏。状态到动作采用公开运行逻辑，窗口交互则使用本宿主现有能力，不宣称源代码逐项一致。

0.1.6 按本插件交互需求，在会话 `running` 期间持续循环工作动作（敲键盘），不采用播放三遍后进入 idle 的行为；退出工作状态后切换对应动作。其余动作维持既有播放规则，减少动画偏好仍优先。

v2 的完整图集、neutral/look16 行定义、16 方向角度顺序和原生触发规则未从公开源确认。目前的 8×11 布局与“顶部起顺时针”注视顺序仅是显式标记的兼容实现。下一阶段须取得原版 v2 资源与播放器行为证据后校正；既有文件中的 `spriteVersionNumber: 2` 本身不能证明映射正确。

## 现有接口边界

| 缺口 | 本阶段已有替代 | 下一阶段所需能力与验收 |
| --- | --- | --- |
| 全会话即时活动与通知推送 | 16 个实时订阅，加公平轮转轻量探测及周期快照；通知查询与已读写入使用真实持久化接口 | 插件可订阅全局会话生命周期、运行状态与通知变化，不以逐会话快照发现新任务；验证大量历史会话下新任务仍能即时出现 |
| 模型输出进度气泡 | 0.1.5 已接入会话模型正文事件和增量拼接，显示当前轮最近片段与会话标题，12 秒无新文字后收起；支持点击打开对应会话 | 仍受现有会话发现与 16 个订阅上限影响；后续全局订阅应承接这条输出通路 |
| 点击拉起主程序会话 | 0.1.5 已增加 `pi.ui.showMainWindow()`，恢复最小化、显示并聚焦主窗口，再走既有 `session/open`；无会话时不创建空会话 | 需更新主程序后实机验证；不等同于浮窗无焦点显示能力 |
| 无焦点显示、隐藏与恢复 | `ui.openPanel` 显示、`ui.closePanel` 关闭；草稿和位置单独保存 | 原生 widget show/hide/showInactive 与焦点控制；验证后台状态变化、启用插件、切换应用时不抢焦点，主动快捷输入才聚焦 |
| 原生关闭前可靠保存 | 输入立即排队保存；插件菜单隐藏前等待附件读取、发送和草稿回执 | 提供可等待的 before-close 或宿主托管草稿通路；覆盖原生菜单关闭、停用插件、宿主退出和进程崩溃。强制终止前未完成写入不作保证 |
| 系统安装链接关联 | 设置页粘贴并导入 HTTPS 图集链接 | 可选协议注册与路由，须避免覆盖原 Codex；冷启动和已运行实例均能打开正确导入页 |
| 原生临时草稿工作流 | 首次发送调用现有 `session/create`，创建后保存 session/message ID 并发送 | 暴露宿主临时草稿、工作目录选择和附件准备的完整流程；创建与发送间失败时避免空会话，保留用户可进入的恢复入口 |
| 宠物包单目录导出 | 下载清单和图集，统一到同目录相对引用 | 可选目录写入或一次性导出包；验证系统下载处理、多文件命名和同名覆盖，不依赖浏览器逐个下载行为 |
| WebP 导入前完整解码 | 后端读取容器/尺寸，页面实际解码并报告损坏；PNG 已有完整性校验 | 提供受支持的二进制图片解码通路；先完成解码再替换旧宠物，防止损坏 WebP 进入库后才被发现 |

主窗口唤起已补 SDK 支持；全局事件、浮窗原生焦点、关闭回执和协议路由仍待后续宿主支持。单目录导出与 WebP 完整解码属于插件实现的后续改进项。
