# 桌面宠物 dsh-pet

将 [PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet) 的桌面核心移植为「这是一个助手 / this-is-a-agent」的独立插件。插件 ID 为 `local.dsh-pet`，使用宿主的 Electron 透明 widget 窗口。

## 功能

- 106 段 VP9 Alpha 透明动画，随机待机、转身、动作点播和双视频缓冲切换。
- 拖拽弹簧跟手、甩抛、屏幕边缘反弹、落地摩擦和点击反馈。
- 多显示器工作区漫游、透明区域鼠标穿透、窗口置顶。
- 最多 8 只宠物，每只独立设置尺寸、角落、边距和显示状态；可开启宠物之间的碰撞。
- 跟随 PI 会话切换思考、工作、整理、等待、完成、出错动画。
- 可选 AI 碎碎念，使用宿主配置的模型，默认关闭；启用会消耗模型 token。
- 设置持久化在插件设置中，提供右键设置入口和工作面板设置视图。

- 角色可按宠物切换：默认女仆（106 段透明 webm），或 Xiao Dino（Codex v2 精灵图集，原生逐帧绘制，不转视频）。

## 宿主要求

需要包含 `window.pluginBridge.widget.invoke` 扩展的本 fork 主程序。本次源码同时包含该宿主扩展；仅在旧安装版中安装插件不能获得完整桌面功能。manifest 的最低版本约束之外，页面也会检查实际接口。

窗口接口提供 `getState`、`setBounds`、`setIgnoreMouse`、`open`、`close`、`setAlwaysOnTop`。窗口由宿主统一管理，插件禁用或卸载时一并清理。插件只使用自己声明的入口页面和所属窗口。

## 使用

1. 构建包含上述接口的主程序，或使用之后包含该改动的发行版。主程序构建遵循仓库根目录 `scripts/build.mjs` 入口。
2. 按下方步骤生成 `.piplug`，在插件管理中安装并启用，授予声明的界面、后台服务、会话和模型权限。
3. 默认在角落显示一只宽 462 DIP 的宠物。左键点击互动，拖动后松手可甩抛，右键打开动作和设置菜单。
4. 在工作面板中打开「桌面宠物设置」，配置大小、多宠物、漫游、置顶、碰撞和碎碎念。
5. 命令面板提供「桌面宠物：显示宠物」「桌面宠物：收起宠物」「桌面宠物：设置」。

## 构建插件

在仓库根目录执行：

```bash
npm --prefix plugins/dsh-pet install
npm --prefix plugins/dsh-pet run pack
```

打包入口为 `scripts/build.mjs --pack`，成功后生成 `dist/local.dsh-pet-<版本>.piplug`，同步递增插件 patch 版本。仅保留最近一次成功的包和装配目录；失败时保留上一份成功产物。

其他构建模式：

```bash
node plugins/dsh-pet/scripts/build.mjs --bundle
node plugins/dsh-pet/scripts/build.mjs --check
```

`--bundle` 从 `src/shared/` 生成 `widget/shared-core.js`；`--check` 装配插件并执行 devkit 静态检查。生成的共享脚本已放在源码目录，普通页面预览也使用它。

## 实现与边界

| 部分 | 实现 |
| --- | --- |
| 插件入口 | `main.cjs`：配置、宠物登记、碰撞状态、会话订阅和碎碎念 |
| 桌宠页面 | `widget/`：动画、物理交互、窗口位置和鼠标穿透 |
| 设置页面 | `views/`：停靠视图和桌宠设置窗口 |
| 共享逻辑 | `src/shared/`：复用原项目的物理、动作选择、多屏几何和菜单 |
| 图集角色 | `widget/atlas.js`：Codex v2 图集的行规格表 + canvas 逐帧播放器 |
| 资源 | `assets/config.jsonc`、`assets/webm/` 与 `assets/characters/` |

- 初始角落使用宿主返回的第一块显示器。该接口尚未提供主屏标记，第一块不保证是系统主屏。
- 手动收起单只宠物只影响本次运行；重启后按保存的显示设置恢复。
- 连续聊天与持久化聊天记忆、系统通知和表情包配图尚未移植。宿主已有模型调用及通知接口，可在后续适配；它们不是宿主不支持的功能。
- 账户余额查询尚未接入服务商接口。6 段余额动画保留为可点播动作。
- 浏览器预览只能展示页面效果，真实透明置顶窗口、跨屏移动和桌面鼠标穿透需要插件在新版宿主内运行。

## 角色（逐宠物）

每只宠物有一个 `character` 字段（可选，**省略 = `maid`**，因此旧设置与旧配置文件不受影响）：

| 角色 id | 素材 | 播放方式 |
| --- | --- | --- |
| `maid`（默认） | `assets/webm/` 的 106 段 VP9 Alpha webm | 双 `<video>` 缓冲切换（原有路径） |
| `xiao-dino` | `assets/characters/xiao-dino/spritesheet.webp`（Codex v2 图集） | `widget/atlas.js` 按行逐帧画到 `<canvas>` |

设置入口：右侧工作面板「桌面宠物设置」→ 多宠物 → 每只宠物卡片里的「角色 Character」下拉；保存后宠物窗口按新角色重挂。角色动作池写在 `assets/config.jsonc` 的 `characters.<id>` 段（未写的字段回落条目级配置），行结构写在 `widget/atlas.js`（两边 id 必须一致）。

### Xiao Dino 图集

- 布局：Codex v2 标准 8 列 × 11 行，每格 192×208，全图 1536×2288。
- 逐行帧数由素材非透明格实测，不是「每行 8 帧」：row0 `0..5`、row1/2 `0..7`、row3 `0..3`、row4 `0..4`、row5 `0..7`、row6/7/8 `0..5`、row9/10 `0..7`。row0 第 6 格与第 0 格姿态几乎一致（alpha 差异 0.3%），按独立的静态 `neutral` 格处理，不进待机循环。
- 行 → 行为映射：row0 待机、row1/2 向右/向左奔跑（自带朝向，行进方向与 facing 由行决定）、row3 挥手（点击回应与碎碎念）、row4 跳跃（完成档）、row5 失败（出错档）、row6 等待档、row7 工作档（标准名 running/work）、row8 审阅（整理档）。思考档复用待机行；图集没有专门的拖拽姿势，`drag` 留空（拖拽时不换动作）；也没有余额专行，不配置 `balance` 事件。
- 帧时长没有可查的权威规范，取值为本插件的显式选择（写在 `widget/atlas.js`：待机 150ms、奔跑 110ms、挥手 150ms、跳跃 120ms、失败 130ms、等待 180ms、工作 110ms、审阅 160ms）。改这些数字即可调整快慢。
- 尺寸与命中区：画布按 192×208 等比 contain 进 9:16 舞台（居中、脚踩舞台底线），窗口/抛掷/漫游几何与视频角色一致，物理手感不变；命中区改为素材非透明像素并集包围盒（格内 `5,5..186,202`）的等比换算，点击与穿透贴合小恐龙本身，而不是整块 9:16 舞台。
- 空闲鼠标关注：row9 的 8 格 + row10 的 8 格 = 16 个视线方向（索引 0 = 正上，顺时针 22.5° 步进）。仅当前台是待机动作、光标在宠物中心 0.9×宠物宽以内（半径是本插件的启发式取值，写在 `widget/atlas.js`）、且不在拖拽/飞行/走动/开菜单时，才改画对应视线格并冻结该行动画时钟；光标离开立即恢复。视线格与角度顺序按行规范实现，**没有**从素材逐格验证（本机没有该规范文件）。
- 边界：图集角色不做整体镜像（方向由行自带）；跨宠物碰撞里自己的身体盒按本角色命中区算，对方仍用 9:16 舞台的归一化命中区（`physics.petCollision` 默认关闭）；换角色不会自动改宠物的显示名（`name` 是用户自己的字段）。
