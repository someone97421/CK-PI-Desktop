## 本次更新

- 新增同一项目的显式隔离会话：在独立 Git worktree 中并行开发，支持初始化、同步、合并预览、冲突保留和可写子代理工作区。
- 强化数据目录迁移与启动维护：兼容首次运行 profile、物理归档、Windows 链接和长路径；存储冷维护等待业务入口加载，协议权限仍提前注册，启动失败会显示可读原因。
- 修复远程 pi-host 会话消息持久化：数据库或宿主暂时不可用时消息进入本地待写队列并退避重试，进程重启后继续补写，避免工具结果静默丢失。
- 修复 TaskResume 接近长度上限时把已完成子代理错误标记为失败、无法再次召回的问题。
- 目录型技能删除时连同同目录资源一起移除，同时避免误删技能根目录或其他技能。
- 同步上游桌面修复：HTML 产物回到所属会话、插件 JSX 与恢复通知、工作区差异、图片尺寸、阅读位置、归档项目、窗口状态、损坏转录、PowerShell 输出、供应商探测、配置路径和自动化会话复用。
