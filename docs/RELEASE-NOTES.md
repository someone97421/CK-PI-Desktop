## 本次更新

本次为相对 latest 正式版 [20261022-164408（v2610.2216.4408）](https://github.com/someone97421/CK-PI-Desktop/releases/tag/v2610.2216.4408) 的累计更新，包含其后三轮上游同步与本 fork 适配；中间预发布不改变此基线。

- 简化自定义模型服务的密钥填写：新服务留空即无需 API Key；编辑时留空保留旧密钥，支持查看密钥及显式清除后保存，取消编辑不删除凭据。
- 工作面板支持更小的宽度，为聊天留出更多空间；调整子代理派发指引，保留按任务收益判断的原则。
- 新增默认关闭的聊天内嵌可视化：在本地对话中生成交互图表，支持展开和主题跟随；开关从下一次发送起更新生成能力，关闭时隐藏已有卡片但保留文件。
- 内置浏览器支持后台页面保活：隐藏面板、切换会话后仍可操作，界面重载后恢复标签；继续支持临时工作目录和隔离会话。
- 聊天顶栏增加项目面包屑和标题行内改名，补充逐轮 token 用量，改善过程分组、阅读位置恢复、文件引用和市场加载失败后的列表保留。
- 输入框补齐右键编辑菜单及命令、技能插入入口，修复滚动打断菜单和迟到的发送失败恢复过时草稿的问题。
- 模型设置增加 reasoning_effort 的自动、发送、不发送选项，保存、复制和配置导入导出保持一致；更新模型目录，保留自定义窗口和模型绑定。
- 修复工具停止等待、提供商复用工具 ID、长会话输出预算、过期系统证书和空回复持久化问题；扩展上下文回调覆盖每轮首个请求。
- 继续保留 TaskResume、当前轮引导、任务抽屉、引用与批注、固定侧栏和外观定制；数据库 schema 24、protocol 11 不变。

内嵌可视化首先支持本地主代理，历史卡片显示当前文件内容；浏览器保活不包含应用重启后的页面状态恢复。
