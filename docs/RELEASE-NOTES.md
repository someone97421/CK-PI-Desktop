## 本次更新

本次为相对上次 latest 正式版 [20261018-201204（v2610.1820.1204）](https://github.com/someone97421/CK-PI-Desktop/releases/tag/v2610.1820.1204) 的累计更新。

- 插件市场卡片补充四行简介、评分底栏和每日精选公开评论轮播，保留市场源、默认/更新/首次发布时间排序及对应日期展示。
- 文件审查恢复原生逐次修改卡与右侧基础审查面板；按文件汇总、分组和本轮／整会话筛选拆分为可卸载的 `local.file-review` 插件，卸载只移除增强入口。
- 内置终端插件适配应用浅深配色与主题资源，改善终端和插件面板外观一致性。
- 修复 Windows 盘符根目录、UNC 共享根目录或 POSIX `/` 作为工作区时，内部相对路径被误判越界的问题，覆盖插件文件、项目指令和浏览器本地文件访问。
- 补齐历史德法西语默认会话标题识别，避免旧数据中的占位标题被当作手动命名；界面仍仅提供简体中文和 English。
- 侧栏项目运行数量徽标与活动轨道继续默认开启；本次不提升数据库 schema 或协议版本。
