## 本次更新

相对 latest 正式版 **20261105-004759（v2611.500.4759）** 的累计更新；基线源码为 `aed8882189e4256aee8272bdcd1e38046cf6f2e7`，中间预发布不改变此基线。

- 升级 Pi 1.5，改善供应商兼容与错误识别，支持显示提供商实际响应模型和费用来源。
- 模型选择改为双栏菜单，思考档位采用分段显示；支持通过 `@agent` 指定子代理，保留现有模型绑定与 TaskResume。
- 接入本地后台 Bash 和统一任务面板，可查看输出、等待和停止后台任务；补齐工作区环境、进程收尾及临时文件清理保护。
- Windows 命令可按需打开独立可见控制台，修复引号和进度输出；保留后台执行与可见控制台的独立操作语义。
- 完善 Google 原生搜索、来源与历史回放，适配 Google 思考档位；保留自定义服务和已保存配置。
- 改善目录粘贴、目录链接和文件管理器定位，保留输入框内目录卡片、临时草稿和隔离工作目录。
- 修复长会话历史加载与“回到最新”的阅读定位、审查文件摘要、启动恢复和侧栏运行数量重复显示。
- 远控项目会话首屏显示 3 条，每次增加 5 条；统一启动器磁贴样式，保留原有面板宽度与外观定制。

本次为 macOS arm64 / x64 与 Windows x64 桌面预发布，包含 Windows 安装版和单文件便携版，不包含新的 pi-host 主机包。

## 验证与兼容

已完成本机 macOS ARM64 完整打包，以及 DMG 完整性、应用签名、架构、版本和更新文件哈希校验。云端流程分别原生构建 macOS 双架构与 Windows，并在产物齐全后创建预发布；具体结果以本次 Actions 为准。本轮未运行单元／E2E 用例，不代表已完成安装启动实机验收。

数据库升级至 **schema 28**，转录格式 **2**、protocol **11**。迁移前自动备份，并按真实文件系统身份归并项目目录别名。升级前请完全退出应用并备份实际业务目录（默认 `~/.pi-desktop`）；仅支持 schema 27 或更早版本的安装包不能打开升级后的数据库，完整回退须恢复升级前整份业务目录。
