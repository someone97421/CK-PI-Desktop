## 本次更新

相对 latest 正式版 [20261101-170229（v2611.117.229）](https://github.com/someone97421/CK-PI-Desktop/releases/tag/v2611.117.229) 的累计更新；基线源码为 `17c6195c459a88c6d8a07526017f135d0ed41921`，中间预发布不改变此基线。

- 修复子代理文件批次使用的工作区身份，使文件操作与所属委派工作区保持一致。
- 主会话、子代理及各自的压缩请求支持向本机 ZCode Pool 桥接传递所属会话工作目录，覆盖项目、隔离 worktree 和临时会话目录；远程工作目录暂不支持。ZCode Pool 为单独安装的可选插件，使用本机已登录的 ZCode Start Plan 通道，其工具由 ZCode 执行。
- 安装插件后同步登记其模型提供商配置，改善模型插件安装后的可用性。

本次为 macOS arm64 / x64 与 Windows x64 桌面预发布，包含 Windows 安装版和单文件便携版，不包含新的 pi-host 主机包。

## 验证与兼容

发布准备仅核对本次增量及发布说明，未在本地运行测试、构建或启动服务。云端双端构建、架构与产物检查结果见本次 Actions 记录；不代表完成安装启动、ZCode 插件完整流程或跨平台实机验收。

数据库 **schema 27**、转录格式 **2**、protocol **11** 不变。新版兼容旧记录；升级前请完全退出应用并备份实际业务目录（默认 `~/.pi-desktop`）。只支持 schema 25 或更早版本的安装包不能打开该数据库，完整回退须恢复升级前整份业务目录。
