## 本次更新

相对 latest 正式版 **20261109-183418（v2611.918.3418）** 的累计更新；基线标签对应源码为 `26f9afb11cfa70a01b95d291413dc328d19d12b8`，中间预发布不改变此基线。

- 主程序内置 Browse CLI 与 MCP，本机浏览器扩展打开即用，无需安装依赖、手动配对或填写 MCP 配置；修复 Relay 启动后卡在待配对状态的问题。
- 本机扩展使用独立内存会话，直接访问远控端口网页仍需密码登录，包括 localhost。关闭私网远控后保留本机侧栏连接，用户已保存的插件禁用选择继续保留。
- 局域网远控升级至 V2，使用桌面原始聊天界面，统一浏览器侧栏与手机网页入口，保留密码登录、设备授权及既有模式控制；移除影响正常会话的请求频率限制，修复重连后的运行状态、队列及历史读取。
- 接入配套 Chrome 扩展，支持标签页、选文与 DOM 元素引用；DOM 准星集成聊天输入工具栏，拖动时只显示网页目标轮廓，确认后将引用加入当前输入框，无需预先放置光标。
- 远控文件菜单新增预览和下载，支持文本、代码、HTML、图片、PDF 与音视频，HTML 可加载相对资源；文件按所属会话读取，系统打开和定位操作交给桌面主机，SSH 工作区的完整文件预览下载仍暂不支持。
- 修复窄屏侧栏菜单越界、子菜单定位和浏览器侧栏布局，补齐扩展中文说明与主程序互链；配套扩展 0.0.19 以固定 ID 的独立 ZIP 发布。
- 完善 Goal 运行控制：支持默认预算、运行中编辑目标和预算、暂停收尾、继续、停止及移除运行；局域网远控同步提供这些入口，Goal 期间继续展示待办与后台任务。
- 侧栏会话状态接入宠物动作，更新内置宠物插件及局域网远控插件；保留固定侧栏宽度和现有主题定制。
- 粘贴磁盘文件改为路径与大小引用，避免复制大文件或内联原图；保留截图、选择器和拖放的原有导入方式，并适配临时草稿与独立工作目录。
- 修复压缩恢复后的工具调用与结果配对、中文保留文本预算和子代理摘要续接；文件变更摘要按实际成功执行的调用收集，继续保留独立压缩模型与 TaskResume／Guide／Inspect。
- 改善长会话字符级阅读锚点和 Markdown 重建后的定位，修复中日韩文本强调解析；保留批注导航、过程自动收起和底部跟随。
- 修复会话模型绑定、模型发现失败退避、模型输出上限及错误识别；补充输出 token 截断提示，改进失败或中断轮次的思考回放。
- 修复手动压缩期间排队、会话切换与历史缓存竞态、当前轮引导后的消息身份；停止或问答提交失败时保留可重试状态，改善模式快照创建和普通模式启动。
- 改善 macOS 后台任务停止、插件 JSON 设置保存、MCP OAuth 失败收尾、文件菜单与 Git 查询超时；损坏 outbox 文件隔离保留原字节，空队列原子写入，并优化桌面打包体积。
- 统一内置执行与修复子代理为 worker，保留 TaskResume／Guide／Inspect；改善联网来源定位、模型选择面板、项目 MCP 配置隔离、插件名称校验及缓存 token 统计。

本次为 macOS arm64／x64 与 Windows x64 桌面预发布，包含 Windows 安装版和单文件便携版，不包含新的 pi-host 主机包。

发布前远控插件 62 项、扩展会话与侧栏 20 项、桌面内置插件配置 12 项定向回归通过，扩展类型检查通过；桌面类型检查仍有此前的 21 项既有诊断，无本轮新增。远控插件 2.0.15 已重新打包，主程序增加随安装包交付的原生 Browse CLI。本次云端流程从同一源码、同一构建时间分别原生构建 macOS 双架构与 Windows，产物齐全后创建预发布；具体结果以本次 Actions 为准。本轮尚未完成新安装包的人工安装及浏览器全流程验收，macOS 使用临时签名且未经公证。
