## 本次更新

相对 latest 正式版 [20261102-004957（v2611.200.4957）](https://github.com/someone97421/CK-PI-Desktop/releases/tag/v2611.200.4957) 的累计更新；基线源码为 `312005c6e079ed72621837598e08679a9c279ad3`，中间预发布不改变此基线。

- 配置备份补齐通用、AI、生图/语音和网络等设置分组；导入统一提供完整覆盖、合并更新和仅添加新项，继续隔离插件托管配置。
- 内置局域网远程控制、会话标题和 Codex 宠物三个可选插件，首次登记默认关闭，沿用已有启停选择与设置；修复会话标题生成的模型补全初始化。
- 局域网远控新增临时会话分组，可打开已有无项目会话，或指定电脑工作目录新建临时草稿；首次发送时才建立正式会话并导入附件。
- 修复远控首次进入会话时显示模型底层标识的问题；新增可保存的页面比例设置，支持 75%～150%，刷新远控页面后生效。
- 统一远控管理页与模型设置的下拉菜单样式，改善搜索框、菜单选中态与展开方向，并为工作过程展开内容增加左右留白。
- 会话标题默认提示词改为中文，并明确沿用用户语言生成标题，保留用户提示和助理回复上下文。

本次为 macOS arm64 / x64 与 Windows x64 桌面预发布，包含 Windows 安装版和单文件便携版，不包含新的 pi-host 主机包。

## 验证与兼容

本次发布准备完成相关语法、差异检查及远控插件打包和模拟页面预览，未在本地运行测试或主程序构建。云端双端构建、架构与产物检查结果见本次 Actions 记录；不代表完成安装启动或跨平台实机验收。

数据库 **schema 27**、转录格式 **2**、protocol **11** 不变。新版兼容旧记录；升级前请完全退出应用并备份实际业务目录（默认 `~/.pi-desktop`）。只支持 schema 25 或更早版本的安装包不能打开该数据库，完整回退须恢复升级前整份业务目录。

配置备份导出格式升级为 **v2**，新版仍可导入旧 **v1** 文件；旧客户端不支持导入新版 v2 备份。
