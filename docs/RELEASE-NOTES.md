## 本次更新

相对 latest 正式版 [20261028-111139（v2610.2811.1139）](https://github.com/someone97421/CK-PI-Desktop/releases/tag/v2610.2811.1139) 的累计更新；基线源码为 `623b51a1efa1685ecba9c13aeda8124b73c23989`，中间预发布不改变此基线。

- 修复 Windows/macOS 进入模型设置页时出现 `busyId is not defined` 的崩溃，统一默认模型和压缩模型选择的忙碌状态。
- 修复 macOS 访达“在此处开启临时会话”重复启动进程、未跳转及未传入目录的问题；Windows/macOS 临时会话绑定目录后，`@` 支持检索文件并添加引用 chip，切换目录不混用缓存，同时修复中文文件名索引。
- 升级 Pi 运行时至 1.4.0；新增默认关闭的 `/fast`，须先在模型配置允许，再按会话开启，仅支持的 Responses 请求使用优先服务档，可能增加费用或消耗订阅额度。
- 工具图片及重复文本镜像采用无损去重存储；删除、撤回和历史分支切换按消息 ID 操作，改善大截图会话的历史操作，继续保留失败消息及真实持久化回执。
- 修复余额/配额耗尽反复重试、畸形工具调用阻断会话、DeepSeek 思考字段回放、超大尺寸图片请求失败，以及路径锁和 Windows 工具子进程清理问题。
- 关闭再打开窗口可恢复真实运行状态；空输入时可用引导快捷键发送排队消息。新增原生本轮文件变更摘要，保留过程自动收起和主动阅读位置。
- 修复插件页面重载残留、工作面板标签菜单遮挡，插件页跟随字号与缩放；模型/供应商/插件操作使用独立忙碌状态。
- 内嵌可视化预加载图表助手，补充静态诊断和运行错误展示，保留原有进度沟通规则。

继续保留 TaskResume、追加式协调状态、分钟提醒、当前轮引导、任务抽屉、引用批注侧边对话和外观定制。独立 `local.file-review` 插件源码已适配原生摘要，0.1.2 插件包不包含在本次桌面发布中；已安装旧插件不会自动更新。

## 升级前备份

本版数据库升级到 **schema 27**、转录格式 **2**，protocol 仍为 11。新版兼容旧记录，旧转录在后续写入时校验并转换；旧版无法打开升级后的同一数据库。请完全退出应用后备份实际业务目录（默认 `~/.pi-desktop`）；需要完整回退时恢复整份目录，单独数据库备份不覆盖后续转录转换。
