## 本次更新

相对 latest 正式版 [20261029-121210（v2610.2912.1210）](https://github.com/someone97421/CK-PI-Desktop/releases/tag/v2610.2912.1210) 的累计更新；基线源码为 `4304ca7450ff76b563c1486e07ad9ce5a0a3e7b9`，中间预发布不改变此基线。

- 子代理失败后保留完整上下文时可显式 TaskResume，支持内存续接及快照冷恢复；保留失败状态、错误报告和执行轮次校验，避免误用上一轮快照或结果。人工停止、撤销、中断或上下文不完整时不自动重跑。
- 支持向具备视频输入能力的模型发送视频，并提供可选 Litterbox 临时文件托管设置。
- 修复缓存 token 未计入上下文预算导致压缩偏晚、压缩完成后占用环未及时更新，以及摘要遗漏近期文件操作的问题；继续保留独立压缩模型。
- 改善模型签名回放、流式重试与空闲超时，修复余额耗尽反复重试、部分 Gemini 错误分类及中文等工具参数的输出预算。
- 文件读取批次由宿主协调资源与取消收尾；Read、Glob、Grep 支持并行读取，Write、Edit 继续串行。审查状态改为追加写入，改善历史保存和缓存恢复。
- 技能与 MCP 的全局/项目开关正确读取和重置项目覆盖，MCP 市场遵循选定安装位置；插件新增已登记项目列表接口，并加强命令注册归属校验。
- 定时任务新增总开关；关闭后隐藏入口、停止到期派发并拒绝任务变更。改善中文输入法、聊天运行状态、环形菜单及工具入口滚动，保留完成后过程自动收起与底部跟随、主动阅读时的位置。
- 修复阻塞 macOS 构建的重复声明、测试 mock 类型及 Rust 缺失导入；可视化内容调整块布局和间距，SSH 安装/启动失败提示更明确。

继续保留 TaskResume 快照、追加式协调状态、分钟提醒、当前轮引导、任务抽屉、引用批注侧边对话和外观定制。快照为普通 JSON，保存开关缺省关闭。云同步及远程主机入口继续遵循既有开发者模式显隐规则，本次桌面发布不包含新的 pi-host 主机包。
