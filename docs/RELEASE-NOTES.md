## 本次更新

相对 latest 正式版 [20261102-144720（v2611.214.4720）](https://github.com/someone97421/CK-PI-Desktop/releases/tag/v2611.214.4720) 的累计更新；基线源码为 `3f008f96e76d6b6ce823e35fbfe191b46a293ada`，中间预发布不改变此基线。

- 新增默认关闭的内置顾问子代理，可绑定独立模型，以只读方式提供困难开放决策的第二意见。
- 修复编辑旧消息重发后，主代理仍收到已丢弃分支失败子代理状态的问题；切回旧修订时仍可召回对应任务。
- 修复取消退出应用时定时任务运行器被提前关闭的问题，并串行处理会话中止与准入，避免运行状态竞争。
- 会话临时文件超过 1 GiB 时缩短闲置清理周期；目录链接仅移除入口，不再阻断自动清理。
- 本轮文件变更摘要默认折叠，保留逐文件查看；改善工作面板工具入口溢出时的导航与定时任务结果文案。
- 补齐插件中心、开发接口及安全模型的中文文档，并澄清插件分发与能力约定。

本次为 macOS arm64 / x64 与 Windows x64 桌面预发布，包含 Windows 安装版和单文件便携版，不包含新的 pi-host 主机包。

## 验证与兼容

本轮子代理分支修复已通过 6 项定向测试，并完成 Windows 本地打包。云端 macOS 双架构与 Windows 构建、架构及产物检查结果见本次 Actions 记录；不代表已完成 macOS / Windows 安装启动实机验收。

数据库 **schema 27**、转录格式 **2**、protocol **11** 不变。新版兼容旧记录；升级前请完全退出应用并备份实际业务目录（默认 `~/.pi-desktop`）。只支持 schema 25 或更早版本的安装包不能打开该数据库，完整回退须恢复升级前整份业务目录。

配置备份导出格式为 **v2**，新版仍可导入旧 **v1** 文件；旧客户端不支持导入新版 v2 备份。
