## 本次更新

- 恢复 Windows 11 主窗口的原生边框能力，修复贴边吸附和双击边缘单向拉伸所依赖的窗口样式，保留自定义标题栏与系统圆角；记录为后续同步须保留的体验。
- 技能支持从压缩包导入，修复耗时统计的翻译键显示。
- 修复停止后立即继续与旧轮清理冲突的问题；当前轮引导后，子代理卡片继续显示真实运行状态。
- 会话耗时分别展示网络等待、模型流式输出和工具调用，并行工具不重复计时。
- 自定义模型服务支持无需 API key，保存无认证设置时清除旧密钥，避免发送占位认证值。
- 浏览器支持显式打开工作区外已存在的本地文件；修复弹窗拖选误关闭、悬停卡片选中文本时消失、侧栏底部菜单定位和表格预览的键盘焦点处理。
