## 安装与兼容

本次提供 macOS arm64、macOS x64 和 Windows x64 桌面预发布。Windows 提供安装版与单文件便携版。macOS 使用临时签名且未经公证。

数据库为 **schema 33**，转录格式为 **2**，宿主协议为 **11**。升级前请完全退出应用并备份实际业务目录（默认 `~/.pi-desktop`）。如需回退到旧版，请一并恢复升级前的完整业务目录。
