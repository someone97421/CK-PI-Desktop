## 本次更新

本次为相对上次 latest 正式版 [20261014-220438（v2610.1422.438）](https://github.com/someone97421/CK-PI-Desktop/releases/tag/v2610.1422.438) 的累计更新。

- 新增手动创建的隔离会话，在独立 Git worktree 中并行开发，支持初始化、同步、合并预览和冲突处理；可写子代理使用独立工作区，保留 TaskResume 续跑与召回。
- 数据存储迁移支持复制校验、进度、失败重试及浏览器数据一并迁移，兼容旧目录配置并保留子代理快照与当前轮引导回执；默认数据目录缺失时可选择恢复已有数据。
- 插件中心新增公开评分、只读评论和已安装插件卡片网格；技能与 MCP 市场加载失败后可直接重试，修复启动恢复后插件界面未加载及 JSX 兼容问题。
- 内置文件管理器新增 PDF 只读预览，支持连续阅读、单双页布局、缩放、缩略图、书签和全文查找；HTML 文件支持选择内置浏览器、系统浏览器或文件管理器打开，并按所属会话目录定位。
- 改善聊天历史阅读位置：切换会话和面板回收后恢复位置，运行中阅读历史不再被强制滚到底部，有新回复后重新打开会话可回到最新内容；修复过程渲染崩溃，思考显示开关与工具展开独立控制。
- 侧栏统一操作与复制子菜单，增加项目运行标记及最后回复时间开关；改善待办当前步骤、模型长名称和文件路径展示，模型服务编辑弹窗随窗口高度自适应，退出与关闭确认跟随应用主题。
- 完善技能目录识别、扫描和批量导入，支持清理缺少 SKILL.md 的残留技能目录；媒体理解子代理支持必要的探测、转码和分段预处理，并按原始时间戳报告结果。
- 模型服务密钥支持显隐切换，修复连接测试、StepFun Plan 模型发现和 DeepSeek 请求兼容；自建网关的聊天、子代理和压缩请求保持稳定会话标识。
- 调整未配置时的默认体验：Windows 资源管理器临时会话入口、运行期间防休眠及侧栏运行与时间显示默认开启，网页链接默认使用系统浏览器，全局权限模式默认自动；保留已有明确设置。
- 修复历史版本切换、删除消息及远程会话中迟到输出的持久化问题，未保存消息继续等待真实落盘回执；修复任务召回、定时任务空会话误复用、桌面启动和提问通知跳转。
- 修复超大工具图片阻断会话、不完整 UTF-8 历史读取、Windows PowerShell 输出与退出码、Bash 进程终止隔离及全屏/最大化恢复；桌宠插件更新至 0.1.8，支持自动镜像。

升级提示：本次数据库沿迁移链升级至 schema 24，迁移前自动备份；仅支持 schema 23 或更早版本的旧安装包无法打开升级后的共用数据库。
