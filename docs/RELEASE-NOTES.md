## 本次更新

相对正式版 **20261122-185423（v2611.2218.5423）** 的累计更新，基线源码为 `0a61ad6fedefa0b80b4abd29e0c5c7ccbf5e1b24`。

- 「编辑项目」支持附加指令。保存后从该项目对话的下一轮起追加到全局指令之后，留空时忽略。
- 文件管理器可将本地源码选区按文件和行号加入对话，普通发送、排队及「立即发送」均支持行引用。开发者模式下，远程主机项目在侧栏独立分组。
- 窄面板输入栏保留右侧上下文百分比、模型菜单和发送按钮。常规设置新增开机启动和静默启动选项。
- 改进长任务压缩成功后的检查点续跑。兼容旧版 MCP HTTP+SSE 和带 UTF-8 BOM 的子代理定义，减少流式回复期间文件审查面板的重复计算。
- 修正 Responses 生图模型未配置时的提示，以及目标模式预算耗尽时的文案。

## 安装与兼容

macOS 安装包采用临时签名，未经公证。数据库为 **schema 33**，转录格式为 **2**，宿主协议为 **11**。升级前请完全退出应用并备份实际业务目录（默认 `~/.pi-desktop`）。如需回退，请一并恢复升级前的完整业务目录。
