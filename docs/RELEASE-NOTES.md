## 本次更新

本次为相对 latest 正式版 [20261024-133922（v2610.2413.3922）](https://github.com/someone97421/CK-PI-Desktop/releases/tag/v2610.2413.3922) 的累计更新；中间预发布不改变此基线。

- 新增会话临时文件清理：闲置 72 小时后自动清理，也可从会话菜单手动清理；悬浮卡显示会话占用与可清理空间。保留对话、完整工具输出、附件、可视化、审查记录和子代理恢复材料，运行中及收尾中的任务受保护。
- 子代理详情页支持直接发送文字引导，展示接收与应用回执；修正召回按钮行为，保留停止与 TaskResume 恢复能力。
- 改善长对话阅读：恢复阅读位置后自动续载，切回已缓存会话时保留阅读页，修复错误出现的“加载后续消息”；稳定自动折叠，并保留切换会话前的任务面板折叠状态。
- 优化桌宠鼠标穿透响应、会话空间统计、文件索引和后台扫描，减少重复读取；文件审查按任务区间读取历史，降低长会话开销。
- 完善工具取消处理，减少取消后的搜索等待；优化浏览器后台页面尺寸处理及会话分叉文件读取。
- 修复官方 DeepSeek 端点的 reasoning_effort 参数发送，调整已保存密钥的清除按钮位置，并更新模型目录。

继续保留当前轮引导、任务抽屉、引用与批注、固定侧栏及外观定制；数据库 schema 24、protocol 11 不变。
