## 本次更新

相对 latest 正式版 **20261107-162823（v2611.716.2823）** 的累计更新；基线源码为 `420c5ff691c187998adf3cbd4109b51be2daf63d`，中间预发布不改变此基线。

- 新增提问超时自动选择：在设置中填写等待分钟数，0 为关闭；问答面板显示倒计时，到期自动提交推荐项或第一项，便于无人值守运行。
- 接入可自定义的工作模式，支持模式编辑、分阶段执行、预算与阶段完成检查；Goal 采用阶段内多轮推进，保留旧 Plan／Goal 历史与审批，并修复普通 Agent 模式的启动校验。
- 局域网远控升级至 0.2.37，支持动态模式选择、阶段和预算展示、暂停／继续／停止及阶段确认，沿用主机密码登录授权。
- 修复含折叠消息时上滚和补载历史的来回跳动：阅读定位跳过隐藏正文，提前计算附近消息实际高度，并保留任务抽屉的展开状态。
- 改善长会话阅读锚点、自适应历史分页、有状态 Markdown 和压缩检查点定位，继续保留小地图用户与助手双标记。
- 新增会话及单轮费用展示；改善侧栏布局备份与恢复、定时任务列表及编辑状态恢复、文件审查焦点同步。
- 修复压缩后上下文所属模型的窗口计算、输出预算与思考尾部保留、图像历史预算、DashScope 错误分类和任务参数兼容，保留独立压缩模型与 TaskResume／Guide／Inspect。
- 修复插件跟随所属会话工作目录、MCP 编辑目标项目、文件管理器 Git 超时和文件名称校验、浏览器标签连接清理及截图粘贴等待；临时文件清理继续保留历史模式产物。

本次为 macOS arm64／x64 与 Windows x64 桌面预发布，包含 Windows 安装版和单文件便携版，不包含新的 pi-host 主机包。

## 验证与兼容

发布准备已完成相关源码静态检查；本机 macOS ARM64 构建曾发现并修复 Rust 宏引用错误，随后完整打包及 DMG 完整性、应用签名、架构、版本和更新文件哈希校验通过。本次云端流程将从同一源码、同一构建时间分别原生构建 macOS 双架构与 Windows，产物齐全后创建预发布；具体结果以本次 Actions 为准，构建成功不代表跨平台安装启动验收完成。
