# 无界面主机与实验性 SSH 远程会话

`pi-host` 组合 RACP 服务、Agent Host、Node 运行时和 Rust host-core。数据库及提供商配置由 Rust 宿主管理；RACP 监听回环地址，桌面通过 SSH 隧道连接。

## 使用范围

本 fork 的远程主机入口仅在开发构建开启开发者模式后显示，安装版继续隐藏。桌面和主机应使用同一日期版本。

1. 在设置的远程主机页通过 SSH 配对主机；也可配对已有的直连地址。
2. SSH 主机支持手动勾选提供商并明确同意复制 API 凭据，可选设置远程默认模型。OAuth、插件托管、CLI 及仅本地有效的端点不参与导入。
3. 选择远程项目，或登记已存在的远程绝对目录；新建 Agent / Ask 会话。
4. 发送文本、处理工具审批与问答、查看只读文件和 diff。重连恢复订阅及待处理交互，不重新发送原提示。

当前界面不提供远程终端、附件、会话内模型控制、消息编辑、Plan/Goal 创建、桌面插件/MCP 转发或跨主机移交。远程路径不会激活本地工作区，远程连接不可用时不会转到本地执行。

## 构建与发布依赖

构建统一从仓库根目录执行 `pnpm build:pi-host`，经过 `scripts/build.mjs` 复用北京时间日期版本和成功批次产物清理规则。Linux x64 原生构建编译对应 host-core；其他平台需要显式提供匹配的主机二进制和终端原生依赖。包中包含完整 runtime 分包、manifest 与资产。

SSH 自动安装只从本 fork `someone97421/CK-PI-Desktop` 的同版本 Release 下载 Linux x64 主机包及 SHA-256 校验文件。同步源码或本地构建不等于已经发布这些产物，也不代表已完成另一台机器上的 SSH 安装验证。

相关验证入口为 `test:e2e:remote-mvp` 和 `test:e2e:remote-mvp-ui`，按需授权执行；前者启动隔离的真实宿主与模拟模型，后者使用模拟 IPC 和真实界面组件。它们不能代替真实远程主机的发布下载与连接验收。

## 提供商导入

桌面界面只传选择的 ID，主进程通过 SSH 标准输入把配置及密钥交给远程 `pi-host.js provider-import`。CLI 经运行中宿主的 `pi-host/admin/admin.sock` 完成导入，不启动第二个数据库写入者。自定义业务目录通过 `--data-dir` 指定。

新增私有目录 `pi-host/admin/` 使用 `0700`，socket 和锁文件使用 `0600`；不改变已有业务根目录和 `pi-host` 目录的权限。导入回执继续保存在 `pi-host/provider-sync.json`，不包含原始密钥。

导入只新增配置。完全相同的导入可复用已有结果；本地配置改变时新增远程行，远程配置已修改或删除时跳过。结果只包含导入 ID、跳过原因和默认模型是否设置。移除桌面配对只关闭连接，不删除远程会话、项目文件或提供商配置。

已开始的 SSH 下载、安装尚不支持中途取消；关闭连接会阻止后续登记并释放返回的隧道，但不会回滚已发生的远程安装。
