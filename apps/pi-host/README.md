# 无界面主机与实验性 SSH 远程工作区

`pi-host` 组合 RACP 服务、Agent Host、Node 运行时和 Rust host-core。数据库及提供商配置由 Rust 宿主管理；RACP 监听回环地址，桌面通过 SSH 隧道连接。

## 使用范围

本 fork 的远程主机入口仅在开发构建开启开发者模式后显示，安装版继续隐藏。桌面和主机应使用同一日期版本。

1. 在「设置 → 远程主机（实验性）」使用已有 SSH 密钥、配置或受支持的密码方式配对主机。自动部署优先让远程主机下载包；只有已分类的下载失败允许一次有大小限制、经本地校验的上传回退。新包自带 Node 22+，远程无需安装系统 Node；上传回退可用于远程无法访问发布源的情况。
2. 返回聊天首页，在「创建项目」选择已连接的主机，通过目录选择对话框浏览或填写远程目录，像本地项目一样在桌面命名。
3. 使用常规项目切换器、侧栏和归档入口。新会话使用本地智能体与本地配置的模型，并绑定远程工作区；模型凭据、模型请求、项目元数据及转录保存在本地。
4. 发送消息、在桌面处理工具审批，查看文件与审查结果。Read、Glob、Grep、Write、Edit、Bash 通过主机工作区服务在远程执行；连接中断会明确失败，重连不重放修改操作。

新流程不要求在主机配置模型、登记项目或创建会话。上游已有的旧远程智能体历史仍使用原后端。扩展提供商的模型调用保留在本地；扩展的工作区 `pi.exec` 需要远程适配，当前缺少适配时明确报错，本地模型辅助进程可指定自己的本地工作目录。没有交互式远程终端界面，但本地智能体的 Bash 命令在远程工作区执行。

## 构建与发布依赖

构建统一从仓库根目录执行：

```sh
pnpm build:pi-host
```

入口 `scripts/build.mjs` 复用北京时间日期版本，支持 Linux/macOS 的 x64/arm64 **原生构建**，使用构建进程的 Node 22+。默认编译当前版本的 host-core，也可用 `THIS_IS_A_AGENT_PI_HOST_CORE` 指定匹配本机平台与架构的已有二进制。上游新包不支持 Windows 构建或跨平台、跨架构标签；旧 `--pty` / `THIS_IS_A_AGENT_PI_HOST_PTY` 交叉构建路径已移除。

包中包含 CLI、完整 runtime 分包、manifest、资产、host-core、自带 Node、`bin/pi-host` 启动器和安装脚本。node-pty 是可选依赖：缺失时明确提示不含终端能力；macOS 打包时会设置对应 spawn-helper 的可执行权限。

每次构建在 `THIS_IS_A_AGENT_OUTPUT_DIR` 指定目录（默认仓库根目录 `release/`）创建独立批次。成功后保留最近一批，失败保留上一批成功产物。包名使用与桌面自动安装一致的内部日期版本：`pi-host-<version>-<platform>-<arch>.tar.gz`，旁边生成同名 `.sha256` 文件。多平台复用同一版本时，需传入相同 `THIS_IS_A_AGENT_BUILD_TIME`；后续批次会清理此前批次，应先收集需要发布的文件。

SSH 自动安装只从本 fork `someone97421/CK-PI-Desktop` 的同版本 Release 获取主机包及 `.sha256`。能够原生构建某个平台不表示该平台已经进入发布矩阵或自动安装支持列表；分发自动安装流程前，必须先发布对应平台的匹配产物。同步源码或本地构建不等于已经发布，也不代表完成另一台机器上的 SSH 安装验证。

## 内容校验与安装复用

整包 `.sha256` 校验发布归档；包内 `SHA256SUMS` 覆盖除清单自身外的全部普通文件。安装脚本支持 `--verify` 原地校验，不创建安装状态，并拒绝缺失、修改、额外文件及符号链接等不符合清单的内容。

默认安装根目录为 `~/.pi-desktop/pi-host`，可通过 `PI_HOST_INSTALL_DIR` 覆盖。安装先复制到暂存目录并完整校验，再按清单摘要保存到 `sha256-<digest>` 目录，原子切换 `current` 符号链接。同一内容复用已有目录，但仍校验已有内容；已损坏目录不会原地修复。已有真实 `current` 目录会导致安装失败。Linux 使用 `flock` 安装锁，macOS 使用目录锁；安装无需系统 Node 或服务管理器。

## 工作区服务与验证范围

主机通过 `workspaceTools` / `workspaceFiles` 能力提供工作区工具及文件服务，验证所有者身份；Rust 执行器沿用路径范围与 shell 身份约束。活动调用属于发起连接，连接关闭时取消；参数和结果上限为 1 MiB，操作不重放。

相关验证入口为 `test:e2e:remote-mvp`、`test:e2e:remote-mvp-ui` 和 `scripts/e2e-local-agent-remote-tools.mjs`，仅按授权执行。前两者分别使用隔离的真实宿主与模拟模型、模拟 IPC 与真实界面组件；后一入口覆盖本地智能体的远程工具路由。这些验证不能代替实际发布下载、SSH 登录与另一台机器上的恢复验收，也不代表完整 R2 验收。

已开始的 SSH 下载、安装尚不支持中途取消；关闭连接会阻止后续登记并释放返回的隧道，但不会撤销或立即中断已经开始的远程安装。
